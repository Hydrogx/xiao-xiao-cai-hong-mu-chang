# 小小彩虹牧场 🌈

一个面向 5–8 岁儿童的轻松牧场小游戏，使用原生 HTML、CSS 和 JavaScript 制作。所有游戏画面与图标都由本地 CSS、系统 Emoji 和项目内 SVG 构成；不需要账号、后端、外部图片、美术素材或构建步骤。

## 开始试玩

直接用浏览器打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。GitHub Pages 部署完成后，也可以直接通过仓库的 Pages 地址试玩。

## 游戏内容

- 漫游牧场，与小花、棉棉和花花互动；抚摸动物可以收获彩虹星星。
- 进入鸡舍捡鸡蛋。点击小鸡可以触发下蛋，点击鸡蛋或使用空格键收集。
- 在六块菜地播种，作物随时间生长；成熟后点击菜地或收获按钮收成。
- 在厨房使用鸡蛋、牛奶和蔬菜烹饪五种料理。
- 完成客人订单，获得金币和星星；在商店购买种子与牧场装饰。
- 天气、昼夜、轻柔音效和角色选择。
- 进度自动保存在浏览器本地，刷新后会继续；菜单可以重开存档。

## GitHub Pages 发布

仓库内含 `.github/workflows/pages.yml`。将代码推送到 GitHub 的 `main` 分支后，在仓库 **Settings → Pages → Build and deployment** 中将 Source 设为 **GitHub Actions**，工作流会发布静态文件。项目采用相对资源路径，可以部署在仓库子目录中。

## 本地存档

存档位于浏览器 `localStorage` 的 `rainbow-ranch-save` 键，带有版本号。清除浏览器数据会移除存档；菜单中的“重新开始”可以重置进度。
